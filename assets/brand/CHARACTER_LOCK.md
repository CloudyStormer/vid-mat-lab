# “小内耗”角色锁定规范

## 唯一母版

- 永久原版底稿：`resistor-mascot-identity-master-original.jpg`
- PNG 工作副本：`resistor-mascot-identity-master.png`
- 旧链接兼容副本：`resistor-mascot-reference.png`，内容与 PNG 工作副本相同
- 三维效果参考：`resistor-mascot-3d-locked-reference.png`

用户已明确要求永久以原版底稿为基准。三维参考只负责材质、光影与空间感。后续任何图片或视频生成，都只能改变场景、镜头、动作、道具、服装、光线和表情，不得重新设计、重塑或“优化”角色本身。

## 永久锁定的外形

1. 白色、圆滚滚、头身一体的电阻小人。
2. 身体上下比例、圆度和四肢长度与母版一致。
3. 黑色粗轮廓线完整保留。
4. 面部仍是简洁的二维卡通五官；3D 化只增加材质、光影和空间感，不把眼睛改成写实眼球。
5. 头顶黄色闪电和蓝色电流符号保持母版的形状、相对位置和比例，竖立在头顶外轮廓上。
6. 右上额保留蓝色电路纹。
7. 下半身保留浅灰色电阻区域、白色锯齿电阻纹和蓝色电路纹，不改成深色金属腰带。
8. 只有一张嘴、两只手和两条短腿；手脚保持母版的短圆卡通比例。

## 永久禁止

- 不得把角色改成另一种蛋形机器人、金属机器人或写实生物。
- 不得更换脸型、眼型、身体比例、腰部结构或主色。
- 不得把黄色闪电或蓝色电流符号贴到脸上、画成纹身、缩成小球或替换成天线。
- 不得生成突出眼眶的眼球、重度血丝、恐怖、怪诞或令人不适的表情。
- 不得出现额外头部、头顶小球、第二张嘴、多手、多腿、长腿或人体四肢。
- 不得因为“3D 化”“电影感”“科技感”而重塑角色。

```text
以提供的“小内耗”三维母版作为唯一角色身份参考。严格锁定角色设计和身体比例，只允许改变场景、镜头、动作、道具、光线和表情；不得重新设计、重塑、美化或替换角色的任何结构。
```

```text
角色一致性优先于画面风格；如果场景效果与角色母版冲突，必须牺牲场景效果并完整保留母版角色。
```
