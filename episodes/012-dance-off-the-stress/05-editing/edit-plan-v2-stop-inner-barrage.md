# 第 012 集 v2 剪映方案｜约 17 秒

## 工程参数

- 画布：1080×1920，9:16
- 帧率：跟随动态素材，建议统一 30 fps
- 字幕：白字黑描边；关键词 `STOP`、`事实`、`行动` 分别使用红、白蓝、电路蓝
- 原声：保留四段视频生成时自带的同步中文口播、环境音和关键音效，不分离、不重新配音
- 人声：峰值约 -6 至 -3 dB；内置 BGM 比人声低约 12—18 dB，四段衔接处只做整体响度匹配
- AI 内容标识：发布时开启

## 时间线

| 时间 | 画面 | 口播/字幕 | 剪辑动作 |
|---:|---|---|---|
| 0.0—1.5 秒 | 片段 A 前半，少量弹幕浮入 | 脑子又开弹幕了？ | 弹幕文字逐条淡入 |
| 1.5—4.6 秒 | 片段 A 后半，弹幕快速增多 | 领导一句“再看看”，我能直接脑补到被裁。 | 弹幕轻微漂移、缩放和颤动 |
| 4.6—5.3 秒 | 片段 B，按下按钮 | 停！ | STOP 冲击、冻结、短震动 |
| 5.3—8.0 秒 | 片段 C，弹幕消失 | 可事实只有三个字。 | 卡片模糊、透明并清除 |
| 8.0—12.0 秒 | 片段 D 前半，输入追问 | 与其猜，不如问：具体哪部分需要调整？ | 后期添加蓝色消息文字 |
| 12.0—14.7 秒 | 片段 D 中段，收手 | 没发生的，别提前受苦。 | 环境稳定，音乐变暖 |
| 14.7—17.0 秒 | 片段 D 结尾，直视镜头 | 别让脑补，替你加班。 | 103%—107%缓慢推近，末尾停0.4秒 |

## STOP 冲击转场

1. 片段 B 的生成原声已经包含按下前约 0.08 秒静音；剪辑时保留这一段，不要再次叠加静音或切掉“停”的起音。
2. 片段 B 从按下按钮的动作开始；在接触按钮的一帧切入红色 `STOP` 文字。
3. STOP 缩放关键帧：约 `70% → 118% → 100%`，总时长约 0.18—0.25 秒。
4. 叠加白色闪帧 2 帧，透明度建议 65% 左右；再叠加 0.25—0.4 秒短震动，强度快速由高降为 0。
5. 如果当前剪映能搜到“穿越III”或“闪回”，只作为辅助层使用，建议控制在 0.5—0.6 秒；效果过强时直接改用闪帧＋震动，稳定性更好。

## 弹幕冻结与清除

- 不建议逐层手工做“冻结帧”。先把主画面和所有弹幕文字做成复合片段，在 STOP 切点统一分割并定格 0.2 秒。
- 如果不方便做复合片段，就让每条弹幕的位移动画都在 4.6 秒同时结束，再复制最后一帧保持 0.2 秒。
- 5.5 秒开始把弹幕透明度从 100% 降到 0%，同时把模糊从 0 提高到约 45—60，持续约 0.8—1.2 秒。
- “变清晰2”更适合从模糊到清晰；本集要清除噪音，优先使用“模糊＋透明度”双关键帧。

## 后期文字层

前半段弹幕：

~~~text
是不是嫌我差？
是不是要裁我？
我是不是又做错了？
他那个眼神什么意思？
~~~

STOP 后：

~~~text
事实：再看看
行动：具体哪部分需要调整？
~~~

结尾标题：

~~~text
别让脑补替你加班
~~~

## 原声音轨处理

- 四段生成时必须已经带有同一青年男声的中文口播，剪映中不要使用文本朗读，也不要另配音。
- 先按口播的自然停顿对齐四段，再处理画面；不得把切点放在一个汉字、气口或句尾衰减中间。
- 若四段响度略有差异，只调每段整体音量，使人声峰值接近；不要使用会改变音色的强降噪、变声或自动美化。
- 片段 B 的按钮咔哒、低频冲击和“停”必须同帧；片段 C 的吸入声跟随卡片消失；片段 D 的发送提示音只保留一次。
- 如果某段出现错词、漏词、双人声、音色突变或口型不合，重新生成该段，不用后期拼字补救。

## 导出前检查

- STOP 是否准确落在按钮接触的那一帧。
- 弹幕是否先冻结再消失，而不是一边运动一边淡出。
- 所有 AI 画面是否始终只有一个身体、两只手、两条短腿和一张嘴。
- 弹幕、字幕是否遮挡小耗儿五官和头顶标志。
- 口播“停”是否被重击音盖住。
- 四段是否保持同一音色、语速和普通话口音，且没有后期重配音。
- 结尾追问是否至少停留 1 秒让观众看清。
