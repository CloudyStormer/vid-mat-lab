## 当前主版本 v2

- 用密集脑内弹幕在第一秒抓住经历过职场脑补的观众。
- 让小耗儿亲手按下红色急停按钮，给 STOP 转场明确动作因果。
- 弹幕清空后不只喊口号，而是给出可直接使用的追问：“具体哪部分需要调整？”

## v2 核心创意

领导只说了一句“再看看”，小耗儿脑内已经演到被裁。它按下 STOP，把“事实”和“脑补”拆开，再用直接追问替代反复猜测。

## v2 已锁定口播

~~~text
脑子又开弹幕了？领导一句“再看看”，我能直接脑补到被裁。停！可事实只有三个字。与其猜，不如问：具体哪部分需要调整？没发生的，别提前受苦。别让脑补，替你加班。
~~~
