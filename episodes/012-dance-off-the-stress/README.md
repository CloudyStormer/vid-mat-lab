## 本集目标

- 用一秒可读的“花海里疯狂跳舞”动作抓住观众。
- 用鲜花、花瓣、金币和红包表达“发财了”，用草地野餐表达“终于放松了”。

## 核心创意

发财可能还没到账，但快乐可以先到账；小耗儿先替大家把这一周的内耗跳出去。
