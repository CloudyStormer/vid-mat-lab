# 最终口播 v1｜约 15—18 秒

```text
别划！你发图，我免费帮你变成带色号的电子拼豆图纸，照着就能拼。

前期投稿少，合适的我尽量多做；以后人多了，每期选几张。

下一张做什么？评论区告诉我。
```

## 分段字幕

### 01｜0—2 秒

```text
你发图，我免费做拼豆图纸
```

底部小字：

```text
仅返电子图纸｜不含材料和实物
```

### 02｜2—7 秒

```text
带网格｜带色号｜照着就能拼
```

### 03｜7—12 秒

```text
前期尽量多做
投稿多后每期选几张
```

### 04｜12—18 秒

```text
下一张做什么？
评论区告诉我
```

## 配音

- 前两秒直接、清楚、稍快，重音放在“你发图”和“免费”。
- 中段语速回落，不要像促销叫卖。
- 最后一句带一点邀请感，不喊“赶紧三连”。
