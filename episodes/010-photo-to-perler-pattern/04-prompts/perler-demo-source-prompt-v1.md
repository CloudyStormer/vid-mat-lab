# 小内耗酷图原稿提示词 v1

用途：生成适合压缩为 40×40 拼豆底板的简单原图。重点是清楚轮廓、少颜色和大色块，不追求复杂场景。

```text
使用小内耗永久原版底稿作为唯一角色身份和结构标准，生成一张1:1方形、完整全身、适合转成40×40拼豆像素图的酷感角色原稿。

小内耗站在画面中央，双脚短而稳，一只极短手臂放在身体侧边，另一只极短手臂斜向上指，像刚想到一个好点子；表情是冷静、自信、略带得意的半眯眼和小微笑。动作要简单，缩小后仍能看懂。

背景只有浅冰蓝纯色和一个深海军蓝的大圆形光环，无房间、无地面杂物、无道具、无文字。

采用干净的2D与轻微半哑光3D结合风格，大色块、粗轮廓、少阴影。颜色限制为白、浅灰、黑、电路蓝、深蓝、闪电黄和淡粉，不使用纹理噪点、细碎高光和复杂渐变。

严格保留单一连续白色蛋形身体、上半部大面积五官、黑色粗线条、淡粉脸颊、头顶分开的黄色闪电与蓝色电脉冲、右上额蓝色电路纹、下半部浅灰电阻区、白色锯齿纹、两条短胳膊、两只手、两条极短腿和两只圆脚。没有独立头部和脖子。

禁止额外手脚、长腿、人类膝盖、第二张嘴、第二张脸、头顶圆球、天线、把符号移到脸上、写实眼球、玻璃或金属身体、粒子特效、复杂背景、文字和水印。

角色一致性与像素可读性优先；发生冲突时简化姿势和光影，不改变角色。
```
