# 第 013 集交付状态｜v1

## 项目与审批状态

- 项目：内耗儿绝缘体。
- 单集：第 013 集《外耗不是伤人，是把问题还回去》。
- 版本：`v1`。
- 当前状态：22 秒完整制作包、17 张关键帧和 17 条独立有声视频提示词已完成并验收；正式动态、固定声音小样与成片仍需逐项生成和验收。
- 审批边界：当前文件属于可执行制作资料，不代表动态、音频、剪映工程或最终成片已经完成。

## 工作假设

- 平台与规格：抖音竖屏 9:16，1080×1920，目标 22.0 秒，建议 30 fps。
- 结构：17 个独立 clip；建立镜和回击镜分开，每条最多一名说话者、一个主要动作。
- 小耗儿唯一身份源为 `assets/brand/resistor-mascot-identity-master-original.jpg`；小欧、小伏为本集原创电气系配角。
- 所有 clip 必须有声音；同一角色跨 clip 固定平台实际 Voice ID / 参考音频、模型版本和声音描述，绝不逐片换音色。`VO-*` 只作内部配置编号。
- 视频生成阶段不生成 BGM；剪辑阶段统一添加一条连续、授权明确的魔性鼓点 BGM。
- 黄色粗体黑描边字幕、场景标签、价格暗示、惊雷、重击、震动和 CTA 均由后期添加，生成画面保持无文字。

## 原始思路与改编说明

- 用户草稿的六个生活场景、快节奏结构和“把不合理要求退回去”的爽点得到保留。
- 未提供可核验原创底稿的配角名称与造型没有直接复刻，生产版改为原创小欧、小伏。
- 对攻击性和外貌羞辱内容做了收束：不把年龄、身材、职业或疾病当笑点，不安排推搡、群体起哄或羞辱性惩罚。
- 结论统一为“外耗不是伤人，是把问题还回去”，以边界表达而非攻击他人为观众回报。

## 阻塞问题

1. 三个逻辑 Voice ID 只有描述与分配规则；在实际生成工具中锁定并验收参考音频、模型版本和 seed 前，不得批量生成有声 clip。
2. 17 条动态尚未逐条通过“有音轨、逐字正确、单一说话者、音色一致、无生成 BGM”的验收，因此不能标记为剪辑就绪。
3. 最终 BGM 必须确认可发布使用；授权状态不清楚时不得随成片发布。

## 优化建议

- 先用镜头 001、002、003 验证三套固定声音，再各补一条长句测试，确认语速和尾字不会被 22 秒时间轴截断。
- 每对“建立镜／回击镜”单独生成和验收；失败时只重做对应片段，不牵连其他场景。
- 剪辑先锁声音与 22 秒时长，再加黄色黑边字幕、音效、震动和统一 BGM。
- 优先在手机外放检查 0.6—0.8 秒快切片段是否仍听得清，必要时只调整节奏，不更换 Voice ID。

## 推荐下一步

1. 锁定三条固定声音锚点，登记实际工具参数。
2. 按 17 条视频提示词生成有声、无 BGM 动态；逐条填写验收结果。
3. 按 [剪辑方案](../05-editing/edit-plan-v1.md) 完成 22 秒时间线，并按 [声音方案](../05-editing/sound-plan-v1.md) 混音至对白约 -16 LUFS。
4. 导出后检查字幕、声音、角色结构、AI 标识和“不鼓励攻击”的发布表述，再进入待发布状态。
