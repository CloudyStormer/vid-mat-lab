# 第 013 集剪辑方案 v1｜22 秒

## 工程参数

- 画布：1080×1920，抖音竖屏 9:16。
- 帧率：统一 30 fps；若源素材帧率不同，先转为恒定帧率再剪。
- 总时长：严格 22.0 秒；17 个片段按下表硬切，不用模型生成转场。
- 字幕：全部在剪辑软件后期添加，统一黄色粗体（建议 `#FFD400`）＋黑色粗描边；不使用生成画面里的文字。
- 字幕安全区：主要字幕位于中间偏下但不遮嘴，距离左右边缘至少 8%；结尾标题位于中上区域，CTA 位于底部安全区。
- 画面节奏：建立镜只交代前提，回击镜只保留一个说话者和一个主要动作；数字推近不得超过 4%。
- 音频：17 条源片都必须带同步声音；说话片段只保留已经绑定同一平台实际 Voice ID / 参考音频的干净口播和极轻环境底噪，建立镜只保留连续环境底噪。餐盘、水滴、脚步、衣架、器械、重击和笑声全部后期添加；任何生成片一旦自带 BGM 或不可控一次性音效，直接判退重生。
- 配乐：生成阶段一律不加 BGM；剪辑阶段只铺一条连续、授权明确的魔性鼓点 BGM，并在人声处统一压低。

## 字幕与屏幕文字

- 台词字幕以 [voiceover-v1.md](../02-script/voiceover-v1.md) 和 [subtitles-v1.srt](../02-script/subtitles-v1.srt) 为唯一文字源，禁止自行改词。
- 所有台词、场景标签、标题和 CTA 都用黄色粗体＋黑色描边；可用字号层级区分，但不换成多套字体和颜色。
- 一屏最多两行，每行尽量不超过 12 个汉字；长句按自然语义断句，不能把一个词拆到两行。
- 场景标签只承担“施压前提”，不安排施压方完整口播，以免 22 秒时间轴过载。
- 生成画面中的空白吊牌、色卡、课程板和环境标识保持无字；所有可读文字必须来自后期图层。

## 画面与转场处理

1. 先按声音起止对齐 17 条片段，再锁定 22.0 秒总时长。
2. 片段之间全部硬切；咔哒、重击、叮声承担节奏转场，不使用花哨模板转场。
3. 红底震动、闪白、桌震和结尾放射线均后期叠加；不得用变形特效拉坏小耗儿的身体结构。
4. 同场景建立镜与回击镜必须核对人物站位、视线、道具和光线；餐盘、蓝杯、色卡、队列、吊牌和课程板不能跳变。
5. 第 07 镜小耗儿带水珠；第 12—16 镜按新场景重置为干燥；第 17 镜恢复同款少量水珠作为回调。

## 导出前检查

- 时间线是否从 0.0 秒连续覆盖到 22.0 秒，17 个镜头无空帧、无重复帧。
- 每条源片是否都有声音；有声对白是否只有指定说话者，其他角色是否闭嘴。
- 三个内部 `voice_profile_code` 是否各自绑定已验收的同一平台实际 Voice ID / 参考音频，并跨全部片段保持同一音色、口音、语速与录音质感。
- 是否彻底排除每条生成片自带的 BGM，只保留后期统一的一条连续 BGM。
- 对白响度是否约为 -16 LUFS，BGM 和音效是否没有盖住尾字。
- 所有字幕是否为后期黄色粗体＋黑色描边，且没有生成乱码、错误价格、Logo 或水印。
- 是否避免外貌羞辱、推搡、群体起哄和夸张惩罚，把爽点保持在“让责任回到提出者”。
