## 硬要求

1. 每个源片和交付视频都有可听见的非空音轨，禁止静音。
2. 对白只说一次，逐字一致；其他画面人物闭嘴，不生成背景可辨识人声。
3. 生成片不带 BGM、歌曲或一次性拟音；所有一次性音效和一条统一 BGM 后期添加。
4. 对白建议约 -16 LUFS，最终 True Peak 不高于 -1 dBTP；BGM 在对白段落低于人声 14—18 dB。
5. 任一镜头发生音色漂移、错词、双重人声或口型错位，只重做该镜，不用变调补救。
