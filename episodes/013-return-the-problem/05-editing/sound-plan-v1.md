# 第 013 集声音方案 v1｜固定音色与 22 秒混音

## 不可变声音规则

1. 17 个 clip 必须全部输出有声音的视频文件，不接受静音素材。
2. 说话片段每条最多一名说话者；不说话的角色必须闭嘴，禁止背景人声抢话。
3. 同一角色跨所有 clip 必须使用同一平台实际 Voice ID 或同一参考音频、同一模型版本、同一声音描述和同一 seed（工具支持时）；绝不允许逐 clip 自动换音色。内部 `VO-*` 只是 `voice_profile_code`，不得冒充平台 Voice ID。
4. 三套声音配置不得互换，也不得用另一个随机文本朗读声临时补句。错词、漏词、重音异常、双人声或音色漂移时，整条对应 clip 重新生成。
5. 每条生成片只带同步口播和极轻、连续的基础环境底噪；严禁生成餐盘、水滴、脚步、衣架、器械等一次性拟音，也严禁任何 BGM、歌曲或旋律。
6. 惊雷、咔哒、餐盘、盘底摩擦、水滴、色卡、脚步、衣架、器械、扎心叮、轻噗嗤、低频重击、打脸声、暴击和人群吸气均作为后期独立音效，不交给视频模型自由发挥。全片 BGM 只在后期统一添加一条。

## 混音目标

- 对白总线：约 `-16 LUFS`，建议控制在 `-17 至 -15 LUFS`；短句之间先按听感匹配，再用响度表复核。
- 单条对白峰值：建议位于 `-6 至 -3 dBFS`，避免限幅器把不同角色压成不同质感。
- 环境声：通常比对白低 12—18 dB，只提供空间感；建立镜没有对白时也不得突然放大。
- 后期 BGM：全片使用同一条，常态比对白低 14—18 dB；说话时再侧链或关键帧压低 3—6 dB。
- 音效：攻击瞬态可短暂突出，但不能遮住首字或尾字；重击、叮声优先放在台词后的停顿。
- 最终母带：防止削波，True Peak 建议不高于 `-1 dBTP`；导出后用手机扬声器和耳机各听一遍。

## 生成与验收流程

1. 先验收 `VO-XH-01`、`VO-XO-01`、`VO-XF-01` 三条干声锚点，记录工具、模型版本、平台实际 Voice ID、参考音频路径与哈希和 seed。
2. 先生成镜头 001、002、003 做三角色声音小样；确认音色后再批量生成其余片段。
3. 每条检查：文件是否有音轨、台词是否逐字正确、是否只有一名说话者、音色是否与锚点一致、是否意外带 BGM。
4. 带有模型 BGM、旋律、双人声或明显换音色的片段直接判退，不用后期变声、拼字或强降噪挽救。
5. 剪辑时先按口播自然停顿对齐画面，再加字幕、音效和统一 BGM；不得把切点放在汉字起音、气口或句尾衰减中间。
