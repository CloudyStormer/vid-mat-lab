## 干声样片要求

- 每个角色 6—10 秒，普通话完整句，无 BGM、无环境声、无混响、无变声和无后期情绪滤镜。
- 同一角色后续所有 clip 必须复用上表同一实际 Voice ID 或同一参考音频、模型版本、seed 与复现参数。
- 情绪只允许改变力度和停顿，不得改变基础音高、共振峰、年龄感、性别感、口音、话筒距离和录音质感。
- 若平台没有 Voice ID 或参考音频功能，必须明确记录能力限制；只能以同一文字锚点尽量接近，不能标记“声纹已锁定”。

## 验收签字项

- [ ] 三条样片都有真实可听音轨。
- [ ] 小耗儿为中低音、近讲干声、略疲惫但清醒、冷静利落的普通话青年男声。
- [ ] 小欧为略高、机灵、带一点笑意但不尖细的普通话年轻中性声。
- [ ] 小伏为略低、平直、气声少的普通话年轻中性声。
- [ ] 已记录实际平台、模型、Voice ID / 参考音频、哈希和 seed（若支持）。
- [ ] 已顺序试听并确认三者互不串音；同一角色两次试生的音色、语速和录音距离一致。
