# 第 013 集制作剧本 v1

## 制作原则

- 总成片 22 秒，17 个独立有声素材硬切完成。
- 建立镜只承担冲突前提，回击镜只允许当前角色开口。
- 建立镜最终只取约 0.6—0.8 秒，但源素材建议生成 2.5—3 秒，方便挑稳定帧。
- 回击镜源素材建议 3—4 秒，剪出对白和末尾 0.25 秒闭嘴定格。

## 表演边界

- 情绪强度通过眉眼、停顿和小幅手势表达，不张牙舞爪。
- 回击对象保持短暂停顿，不生成夸张摔倒、捂脸或全场起哄。
- 只有第 07 与第 17 镜保留小耗儿身上的水珠，形成喜剧连续性。
