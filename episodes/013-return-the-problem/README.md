## 改版说明

v1 的临时人物设计不再进入当前生产版，但全部 v1 文件原样保留供追溯。v2 不改六个生活场景、11 句口播、字幕时码和核心判断，只把全部回击统一交给永久 IP 小耗儿，并把声音统一为 `VO-XH-01`。

## 核心判断

“外耗”不是主动伤人，也不是拿外貌、年龄、职业或疾病攻击别人；爽点来自把不合理要求、责任和成本还给提出它的人。

## 22 秒结构

1. 0.0—1.6 秒：小耗儿红底怼脸钩子。
2. 1.6—3.6 秒：同一小耗儿用三种纯色场景完成三连快切。
3. 3.6—19.0 秒：错餐、家长甩锅、理发推销、插队、服装店先入为主、私教硬推六个场景。
4. 19.0—22.0 秒：亮黄背景中只有一个小耗儿点题：“外耗不是伤人，是把问题还回去。”
