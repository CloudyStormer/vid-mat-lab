# 用户原始草拟提示词 v1

> 本文件保留创作输入，不代表所有台词均进入正式生产版。

## 基础参数

抖音竖屏 9:16，时长 22 秒，Q 版手绘动画风格，快节奏爽感剪辑，魔性鼓点 BGM，全程黄字黑边加粗字幕。主角叫小耗，搭配小八、吉伊两个配角，路人对应各场景的讨厌角色。

## 原始分镜

- 0—2 秒：小耗脸怼满屏幕，超凶，红底震动，大喊“你没家啊？！”
- 2—4 秒：小八“那你多吃点，亏都给你吃”；吉伊“你没病吧？”；小耗拍桌“凭什么我买单？”；字幕“外耗型人格，到底有多爽？”
- 4—6.5 秒：店员端错餐仍让顾客将就；小耗回答“那你将就的话，你把钱付了，我将就。”
- 6.5—9 秒：孩子把水泼在小耗身上，家长说“他就是个孩子”；小八回答“是孩子又不是傻子，你当狗养呢？”
- 9—11.5 秒：理发师用“199 伤头发、388 店长染得好”推销；吉伊回答“伤头发你还敢给顾客用？”
- 11.5—14 秒：插队者说大家都没意见；小耗站到她前面回答“既然如此，那我先来。”
- 14—16.5 秒：服装店员暗示价格贵、不适合；小耗以“因为你站在这……”反击。
- 16.5—19 秒：私教硬推课；小耗以对方身材和销售身份反击。
- 19—22 秒：三人并排叉腰歪头，字幕“与其内耗自己，不如外耗别人”，底部 CTA“遇到过哪种讨厌鬼？评论区说”。

## 生产改写说明

- 保留六场景、快切、红底、黄字黑边和爽感节奏。
- 把双人长对白压缩为“动作建立前提 + 一句回击”。
- 删除疾病标签、动物化、体型和职业羞辱；插队场景不让主角也插队。
- 结尾改为“外耗不是伤人，是把问题还回去”。
- 因缺少配角原创底稿，生产版使用原创电气系小欧、小伏。
