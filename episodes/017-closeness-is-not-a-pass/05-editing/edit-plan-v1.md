# 第 017 集剪辑方案 v1

## 项目设置

- 画布：1080×1920，竖屏 9:16
- 帧率：60fps
- 色彩：SDR / Rec.709
- 音频：48kHz
- 目标有效成片：33.70 秒

## 剪映操作顺序

1. 新建 1080×1920、60fps 项目，按 01—08 顺序导入动态源片。
2. 先按每镜有效时长裁切，不保留源片末尾的空转或模型续演。
3. 校对 0.30 秒闭嘴准备、对白区间和 0.45 秒闭嘴收口。
4. 同场景正反打直接硬切；只在 01→02、03→04、05→06、07→08 添加统一黄蓝电流闪切。
5. 导入 `subtitles-v1.srt`，逐字核对原句和时间码。
6. 统一字幕样式，再补环境音、转场音和低音量 BGM。
7. 完成角色、口型、响度和画面安全区验收后导出。

## 字幕

- 字体：使用已获得商用授权的黑体类字体。
- 样式：暖黄色字、黑色粗描边；不使用花字模板。
- 位置：下方安全区，距底边约 12%；避免遮挡小耗儿的腰带、嘴和NPC手势。
- 长句（镜头04、07、08）按自然语义分成两行，但不得改字。
- 不给图片或视频模型生成文字，所有字幕只在剪映添加。

## 转场

- 配方：0.10—0.14 秒黄蓝电流斜划 + 1 帧暖白闪光 + 极轻“啪”声。
- 同一组对话内部不加特效，保留真实正反打节奏。
- 禁止使用会扭曲人物的穿越、液化、旋转或AI补帧转场。

## 导出前抽查

- 抽查每段首帧、25%、50%、75% 和尾帧。
- 确认小耗儿没有牙齿、舌头、头顶球、双蛋、人类五指手、长腿或多肢。
- 确认每段只有指定说话者开口，灰狗始终闭嘴。
- 确认三组原对白、开场、结尾均无错字、漏字或自动续写。
- 确认镜头08抬起的是短圆无分指小手，不是人类手掌。
- 确认最后 0.45 秒闭嘴、目光停稳，不突然黑屏。
