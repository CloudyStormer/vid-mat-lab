# 第 017 集｜亲近，不是越界的通行证

## 当前状态

- 版本：`v1`
- 状态：8 镜完整制作包与 8 张关键帧已完成，待锁定实际声音资产并生成动态片段
- 画幅：竖屏 9:16
- 帧率：60fps
- 有效成片：33.70 秒
- 结构：饭局结束后的玄关自然开场 → 催生/重男轻女 → 长辈 PUA → 同名找茬 → 回到同一玄关自然收束

## 本集原则

- 三组原始对白逐字保留，只按“关系由近到远”的节奏排列。
- 每个动态片段只允许一名说话者和一个小动作；听者留在画外。
- 每镜前 0.30 秒闭嘴准备，末字后 0.45 秒闭嘴自然收口。
- 口播按 5.0—5.6 个汉字/秒审计，8 镜均通过。
- 小耗儿必须以仓库永久母版为唯一身份标准；生成图和视频均禁止牙齿、舌头、头顶球、双蛋、长腿、多肢或人类五指手掌。
- 同场景正反打直接硬切；不同场景只在后期使用统一黄蓝电流闪切。

## 关键风险

- 小耗儿真实平台音色/参考干声尚未登记，不能把内部标签 `VO-XH-01` 当作平台 Voice ID。
- “坟头草都老高了”是黑色幽默台词；画面禁止坟墓、骷髅或惊悚联想，发布配文也不强化攻击性。
- 动态生成后必须抽查首帧、25%、50%、75% 和尾帧；任一帧出现身份漂移或肢体增生，整段重生成。

## 下一步

1. 在 [声音锚点登记](05-editing/voice-anchor-register-v1.md) 填入真实平台音色或 6—10 秒无音乐干声。

3. 按 [剪辑方案](05-editing/edit-plan-v1.md) 只取有效区间，合成 33.70 秒成片。
4. 完成口型、角色、字幕、响度与转场验收后再发布。
