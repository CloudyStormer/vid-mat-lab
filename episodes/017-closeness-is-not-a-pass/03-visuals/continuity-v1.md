# 第 017 集视觉连续性 v1

## 1. 小耗儿永久身份锁

- 唯一身份母版：`../../../assets/brand/resistor-mascot-identity-master-original.jpg`。
- 机位参考：正面使用六视图正面；朝画面左约 45° 使用六视图左 3/4。
- 全程只能有一个横向饱满的近圆白色电阻机体，正面和 3/4 机体宽度不得低于高度的 95%。
- 上半部固定一套大眉眼、鼻子与唯一一张无牙无舌小嘴；下半部固定浅灰电阻腰带、连续白色锯齿纹和蓝色电路纹。
- 头顶只允许黄色闪电与蓝色电流折线两个平面标志；禁止头顶球、第二颗头、双蛋、天线或额外角色。
- 恰好两只短圆手、两条极短腿和两只短脚；禁止人类五指手掌、长腕、长腿、第三只手和肢体增生。
- 相邻帧不得随机镜像；腰带高度、锯齿纹和蓝色电路纹不得跳位。

## 3. 正反打轴线

- NPC 正打统一位于画面左侧、视线朝右。
- 小耗儿反打统一位于画面右侧、视线朝左约45°。
- 同一组内不越轴、不翻转素材、不改变主光方向。
- 同场景镜头直接硬切；不同场景的黄蓝电流闪切只在后期完成，不交给视频模型生成。

## 4. 动态验收

每段至少抽查首帧、25%、50%、75% 和尾帧：

- 角色身份、机体圆度、五官、腰带、纹路、头顶标志是否稳定。
- 是否始终只有两只短手、两条极短腿和唯一无牙小嘴。
- 是否只有指定说话者开口，听者和动物始终闭嘴。
- 0.00—0.30 秒是否闭嘴准备；末字后是否闭嘴并保留 0.45 秒自然停留。
- 出现任一变脸、双嘴、牙齿、舌头、头顶球、双蛋、人类五指手或肢体增生，整段判失败并重生成。
