# 第 017 集口播逐段稿 v1

使用方式：每一段单独复制并单独生成干声；不要一次生成整篇。内部配置名不等于平台 Voice ID，真实声音需先登记在 `05-editing/voice-anchor-register-v1.md`。

## 01｜小耗儿自然开场｜3.60 秒

语气：普通话青年男声，中低音、近讲干声，像饭局结束后平静复盘。

```text
熟人越亲近，越容易把越界当成关心。
```

## 02｜催生亲戚｜3.00 秒

语气：中年女声，理所当然、像把催生当关心，不尖叫。

```text
你也争点气，下一胎生个儿子
```

## 03｜小耗儿回应催生｜2.80 秒

语气：青年男声，平静反问，字音清楚，不咆哮。

```text
那你是哪个不争气的生的？
```

## 04｜长辈比较式 PUA｜5.50 秒

语气：年长女声，缓慢、自我肯定式说教。

```text
我们那时候生完孩子就下地干活了，哪像现在的人金贵得很
```

## 05｜小耗儿回应长辈｜4.30 秒

语气：青年男声，像认真同情，带一点克制反讽。

```text
那你可真挺惨的，牲口干完活都知道休息几天
```

## 06｜同名邻居｜3.10 秒

语气：年轻女声，挑剔质问，像故意找茬。

```text
你家孩子怎么跟我家狗一个名？
```

## 07｜小耗儿回应同名找茬｜6.60 秒

语气：青年男声，先像回忆半拍，再平静说完；黑色幽默但不阴森。

```text
巧了，我老家也有个人跟你同名，坟头草都老高了，不看见你我都忘了这人了
```

## 08｜小耗儿自然结尾｜4.80 秒

语气：青年男声，清醒坚定但不说教；最后六个字落稳。

```text
亲近不是冒犯的通行证。该挡回去的话，当场挡回去。
```
