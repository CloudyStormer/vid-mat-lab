# 第 016 集｜不好笑，就不用陪笑

## 状态

- 当前阶段：8 张关键帧与完整制作包已完成，待登记实际声音锚点并生成动态视频。
- 当前版本：`v1 两组对话精简版`。
- 创建日期：2026-08-11。
- 画幅：抖音竖屏 9:16。
- 帧率：60fps。
- 计划成片：24.85 秒。
- 视觉风格：原创 Q 版二维手绘动画，小耗儿固定 IP。
- 栏目：生活边界｜停止用陪笑消化冒犯。

## 本集目标

- 用两组有来有回的短对话说明：把冒犯包装成“玩笑”，不等于听者必须陪笑。
- 用户给出的六句正文对白逐字保留；只在前后增加已确认的自然开场和自然结尾。
- 每个 AI 片段只允许一名说话者，正文全部使用正反打，不让模型在同一片段内切换说话人。
- 回击保持平视、清楚、不威胁；重点是停止事后反复生气，不是鼓励无差别攻击。

## 结构

1. 傍晚社区小广场开场：小耗儿说明“玩笑”有时是在阻止你翻脸。
2. 写字楼电梯前：对方进行人身攻击，小耗儿当场回击。
3. 社区游乐场：小孩挑事，再用“开玩笑”挡箭，小耗儿追问到底谁笑了。
4. 回到同一社区小广场：小耗儿说明“不好笑，就不用陪笑”。

## 重要决定

- 8 镜均为对白镜头，每镜只有一名说话者。
- 全部源片按 60fps 生成；每镜前 0.30 秒闭嘴准备（18 帧），末字后保留 0.45 秒自然收口（27 帧）。
- 口播共 99 个汉字，净口播 18.85 秒，整体约 5.25 字/秒；加上每镜头尾停留后，成片为 24.85 秒。
- 镜头 001 与 008 使用同一社区长椅、小广场、机位、人物比例和暮色光线，完成首尾呼应。
- 镜头 002—007 复用第 015 集已经验收的对应关键帧，只重新编号，不重新生成。
- 仓库尚未登记任何平台真实 Voice ID 或参考音频；内部编号只用于项目管理，不能冒充平台 Voice ID。当前按外部固定配音模式设计，声音锚点完成前不得宣称声纹锁定。
