# 第 016 集声音方案 v1

## 当前声音模式

本集采用外部固定配音模式。原因：仓库尚未登记任何平台真实 `provider_voice_id` 或可复用 `reference_audio`；只写音色描述无法保证跨片声纹一致。

- 视频模型：只生成与场景匹配的连续轻微环境底噪和精确口型，不随机生成对白声线。
- 配音：使用同一已验收声音资产分别生成角色干声，再无损同步混入源片。
- 内部配置编号只用于项目管理，绝不是平台 Voice ID。
- 实际声音资产未登记前，禁止把本集标记为“声音锁定完成”，也不要批量生成全部动态。

## 三个声音角色

### VO-XH-01｜小耗儿

- 普通话青年男声，中低音、近讲干声、略疲惫但清醒、冷静利落。
- 情绪只改变力度和停顿，不改变基础音色、音高、共振峰、年龄感、性别感或口音。
- 镜头：001、003、005、007、008。
- 建议声音锚点：把开场和结尾两句连续录成 8—10 秒无 BGM、无混响、无环境声的干声，中间自然停顿约 0.5 秒，仅用于验收音色，不作为正片连读。

### VO-016-NPC-ATTACKER-01｜年轻男子

- 普通话年轻男声，轻蔑、克制、不吼叫、不夸张反派化。
- 镜头：002。
- 虽仅出现一次，也必须登记本次实际声音来源，避免把内部编号误写成平台 Voice ID。

### VO-016-NPC-CHILD-01｜小男孩

- 普通话男孩声，起哄、嘴硬，不尖叫、不突然成人化。
- 镜头：004、006；两镜必须复用同一实际声音资产。
- 建议声音锚点：将两句男孩对白按原文顺序录为一条干声，中间留 0.8—1.0 秒停顿，再分别切出正片片段。

## 环境底噪

| 场景 | 镜头 | 连续底噪 |
|---|---|---|
| 傍晚社区小广场 | 001、008 | 轻微风声、远处模糊城市底噪；禁止可辨识人声 |
| 写字楼电梯厅 | 002、003 | 低而稳定的室内空调与空间底噪；电梯提示音后期可选 |
| 社区游乐场 | 004—007 | 轻微户外风声与器械远响；禁止背景儿童对白和笑声 |

三种环境底噪均从源片开始到结束保持可听但不抢对白；一次性电梯提示音或器械轻响统一后期添加。

## BGM 与混音

- BGM：轻量、克制、带一点清醒感的纯音乐；不使用煽情钢琴、罐头笑声或夸张打脸音效。
- 对白建议约 `-16 LUFS`，峰值不高于 `-1 dBTP`。
- BGM 在对白下压约 6—9 dB。
- 相邻镜头的人声音色、音高、语速、口音和录音距离必须连贯；不通过后期变调把不同声线硬修成同一人。

## 验收

1. 先验收小耗儿干声锚点，再试生 001 与 003。
2. 再验收男孩声音锚点，生成 004 与 006 并顺序试听。
3. 检查每个源片和最终成片确实含音轨且不是空音轨。
4. 每句只出现一次，逐字一致；没有叠声、抢词、吞字、自动配乐或背景可辨识人声。
5. 声音锚点和实际生成设置回填到 [登记表](voice-anchor-register-v1.md)。
