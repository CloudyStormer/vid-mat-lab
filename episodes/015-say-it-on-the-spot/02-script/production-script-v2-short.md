# 第 015 集制作剧本 v2-short｜26.55 秒职场边界短版

## 制作原则

- 固定顺序：自然开场 → 打印机两句 → 公司甩锅两句 → 自然结尾。
- 六句逐字锁定，每个 AI 片段只有一名说话者和一个小动作。
- 镜头 001 与 006 使用同一办公室茶水间、同一机位、同一角色大小和光线，但姿态不同。
- 同组正反打直接硬切；两组职场场景之间使用后期短促黄蓝电流闪切。
- 每镜 0.30 秒闭嘴准备；末字后 0.45 秒自然收口，以呼吸、眨眼或目光停稳结束，不僵硬冻结。

## 场景连接

- `002→003`、`004→005`：直接硬切，保持 NPC 左、小耗儿右的轴线关系。
- `001→002`、`003→004`、`005→006`：后期叠加 0.10—0.14 秒黄蓝电流斜划和极轻“啪”声；转场不得压住对白。
