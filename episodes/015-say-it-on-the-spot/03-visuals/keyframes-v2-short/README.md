## 动态生成前检查

- 小耗儿必须是单一横向近圆机体，恰好两只短手、两条极短腿和两只圆脚。
- 唯一小嘴无牙、无舌头；头顶只有黄色闪电与蓝色电脉冲，不得出现圆球或第二身体。
- 正反打听者留在画外；每段只有当前说话者开口。
- 图片无字幕、无 Logo、无水印；字幕与转场只在后期添加。
