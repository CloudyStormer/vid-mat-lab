## 使用原则

- 同一场景的正打和反打使用相同地标、灯光和轴线。
- 小耗儿镜头以永久原版底稿为身份基准，以匹配角度的六视图为结构参考。
- 每张图无字幕、无 Logo、无水印；文字统一后期添加。
- 生成动态视频前先检查：单一近圆机体、两只短手、两条极短腿、无牙小嘴、无头顶圆球、无多余身体。
