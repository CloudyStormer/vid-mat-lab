# 第 015 集｜别人的锅，别背回家

## 状态

- 当前阶段：`v2-short` 六镜短版制作包与关键帧已完成，待生成动态视频。
- 当前版本：`v2-short 职场边界短版`。
- 历史版本：`v1 自然开收场长合集版`，完整保留，不删除、不覆盖。
- 创建日期：2026-08-11。
- 画幅：抖音竖屏 9:16。
- 当前计划时长：26.55 秒；历史 v1 计划时长：68.8 秒。
- 视觉风格：原创 Q 版二维手绘动画，小耗儿固定 IP。
- 栏目：工作与生活边界｜减少事后内耗。

## 本集目标

- 面向被同事甩锅后不敢当场澄清、回家继续反复内耗的年轻人。
- 当前短版只保留两组职场正反打，四句正文逐字不改，主题集中在责任边界。
- 通过同一办公室茶水间自然开场和收束，不把作品剪成孤立回怼片段。
- 回击表演保持冷静、平视、不威胁；核心不是逢人就吵，而是及时说清责任。

## 当前 v2-short 结构

1. 办公室茶水间自然开场：说明最耗人的往往是被顺手甩锅。
2. 打印机甩锅正反打：完整保留原两句对白。
3. “你一来公司就不行了”正反打：完整保留原两句对白。
4. 回到同一茶水间：责任当场说清，不把别人的锅背回家内耗。

共 6 镜，每镜只有一名说话者；所有镜头采用 60fps、0.30 秒闭嘴准备和末字后 0.45 秒自然收口。

## v1 历史结构

1. 玄关开场：小耗儿说明自己以前会忍、回家再内耗。
2. 打印机甩锅：先从账号最核心的职场压力进入。
3. 人身攻击：短促二连，加快节奏。
4. 小孩拿“开玩笑”挡箭：四拍对话形成节奏变化。
5. 催生与重男轻女：进入家庭边界。
6. 长辈 PUA：家庭压力升级。
7. 同名找茬：最长回击，作为高潮前蓄力。
8. 公司甩锅 2.0：回到职场，用最强反问收高潮。
9. 回到玄关：说明不是为了吵赢，并完整保留点题句。

## 版本关系与重要决定

### v2-short 当前版

- `v2-short` 是当前优先制作版，主题聚焦职场边界《别人的锅，别背回家》；只保留两组职场正反打，降低制作量并提高主题集中度。
- v2 的四句正文对白逐字不改；开场和结尾使用本轮确认的固定文字。
- v2 开场与结尾使用同一办公室茶水间、同一机位和光线，但姿态不同，形成自然首尾呼应。
- v2 六句共 117 个汉字，实际说话时长 22.05 秒；分镜语速均为每秒 5.0—5.6 个汉字，有效成片总长 26.55 秒。

### v1 历史版

- `v1` 是 18 镜、七组场景的历史长合集，全部文件继续保留，后续仍可单独制作，不视为废稿。
- 原七组对话共 16 句，全部逐字保留；新增一段自然开场和一段自然结尾。
- 每个 AI 视频片段只允许一名说话者，因此共 18 镜，不在同一片段里让两个人轮流开口。
- 自然语速审计后总口播 296 个汉字，成片计划 68.8 秒；不压成 20—30 秒，不暴力倍速。
- 同场景正反打固定轴线：NPC 在画面左侧朝右，小耗儿在画面右侧朝左；听者留在画外，减少错口型。
- 镜头 001 与 018 使用同一玄关、同一机位、同一人物比例与灯光，完成首尾呼应。
- 从本集开始，多场景合集默认必须有自然开场和自然结尾，不能第一帧直接硬切进孤立场景。
