## 推荐使用方式

最稳的是生成两段独立动态：

1. 关键帧 01 单图生视频，完成严肃接读。
2. 关键帧 02 单图生视频，完成直视镜头吐槽。
3. 两段之间直接硬切，不要求生成模型完成大幅度“放纸—推近”动作，能明显减少手部、稿纸和角色结构漂移。

对应提示词：[`../../04-prompts/video-prompts-v1.md`](../../04-prompts/video-prompts-v1.md)。

## 连续性检查

- 两张均保留白色圆形身体、灰色腰带、腰部锯齿、蓝色电路纹、黄色闪电、蓝色波形天线和黑色粗轮廓。
- 两张均为同类深色木质议会厅、绿色座椅和暖色灯光。
- 稿纸均无可读文字，画面无字幕、徽记、媒体水印或真人。
