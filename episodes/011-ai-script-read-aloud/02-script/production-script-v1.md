# 第 011 集制作剧本

## 单集目标

- 核心戏剧问题：真人现场说到哪里，卡通小耗儿能否无缝接棒并把尴尬放大？
- 本集观众回报：先看到真实证据，再听到一句针对人工校对的短吐槽。
- 目标时长：约 11.8 秒
- 开场钩子：真人现场直接念出 `Here's a more natural, flowing version…`
- 结尾承接：以小耗儿平静直视镜头结束，不再补道理。
- 工作假设：正式开场片段来自官方公开视频；当前精确日期和时间码待核。

## 制作剧本

### 场次 001｜公开议会录像

- 地点与时间：加拿大新不伦瑞克省议会，2026 年 6 月；具体日期待核
- 连续性状态：真实公开素材，只取必要约 2 秒
- 戏剧目的：让观众先亲耳听到异常句式
- 出场角色：Bill Oliver
- 关键道具：讲台、稿件

**可见动作**

Bill Oliver 低头读稿，发言不中断。

**对白**

`Here's a more natural, flowing version…`

**屏幕文字**

身份、月份、中文翻译与官方来源。

**声音与音乐**

只留现场原声；无背景音乐，避免削弱证据感。

### 场次 002｜小耗儿动画复现

- 地点与时间：原创议会风格动画场景，与上一镜构图匹配
- 连续性状态：镜头 002、003 共用同一场景、讲台、稿纸与光线
- 戏剧目的：用视觉接棒模仿放大荒诞感，再完成一句吐槽
- 出场角色：角色-001 小耗儿
- 关键道具：道具-011-A 木质讲台；道具-011-B 白色稿纸

**可见动作**

镜头 002：小耗儿保持严肃，低头接读稿纸。镜头 003：硬切近景，小耗儿把稿纸缓慢放低，停 0.2 秒后看向镜头。

**对白**

镜头 002：`……读起来更像议会演讲，而不是一连串简短要点。`

镜头 003：`AI没抢他的工作，他先把“检查一遍”这份工作辞了。`

**屏幕文字**

镜头 002 角落：`小耗儿动画复现｜原话中文意译`。镜头 003 只保留逐字字幕。

**声音与音乐**

镜头 001→002 用一次轻微纸张翻页或磁带接续声；镜头 002→003 留 0.2 秒干净停顿。全片不要综艺罐头笑声。

**新增素材**

- 镜头 002 中景起始帧
- 镜头 003 近景吐槽帧
- 两段同场景动态
