# 第 008 集｜五段图生视频提示词

## 全局设置

- 画幅：9:16
- 总时长：约 18 秒
- 单段建议：3 秒、3 秒、3 秒、4 秒、5 秒
- 运镜：轻推、轻摇或轻微手持感；不使用剧烈旋转
- 动作幅度：中小幅，避免模型重绘角色

每段提示词开头都必须加入：

```text
使用输入图片作为首帧和角色唯一参考。小内耗的外形、身体比例、五官、黑色粗线条、头顶黄色闪电与蓝色电流符号、蓝色电路纹、浅灰电阻区和短圆四肢保持完全不变。细腻半哑光3D材质，有体积和柔和高光，但不能玻璃化、陶瓷化、镜面化。只允许做指定动作和镜头运动，禁止重绘、变形或添加肢体。
```

每段提示词结尾都必须加入：

```text
全程只有一个小内耗、一张嘴、两只手和两条短腿；禁止多嘴、多手、多腿、长腿、头顶小球、符号漂移、身体穿模、道具凭空出现、闪烁、瞬移和画面文字变形。角色一致性优先于动画幅度，动作困难时宁可减小动作。
```

## 01｜导出完成，3 秒

使用：`../03-visuals/keyframes-v1/01-export-100-percent.png`

```text
夜间剪辑室保持稳定。镜头从中景缓慢向小内耗轻推。电脑导出圆环从98%平稳走到100%，界面不跳动、不乱码。小内耗先看着屏幕，确认完成后露出原本的小得意表情，右手做一次短促克制的庆祝动作，左手始终靠近键盘。台灯和屏幕光轻微变化，其他物体不移动。
```

建议音效：期待上升音 + 很轻的完成提示音。

## 02｜低播放量，3 秒

使用：`../03-visuals/keyframes-v1/02-low-stats-302-3.png`

```text
早晨房间保持安静。小内耗低头看手机，眼神从期待逐渐变成失望，眉毛轻微抬起，嘴角慢慢放平，肩膀只下沉一点。手机始终由双手稳定握住，屏幕中的302和3保持固定清晰。镜头轻微推近面部，动作自然克制，不做瞳孔爆出或夸张惊吓。
```

建议音效：泄气的“噗”或短促下坠音。

## 03｜随手自拍，3 秒

使用：`../03-visuals/keyframes-v1/03-casual-selfie.png`

```text
小内耗一只手稳定举着手机，另一只手保持随意的剪刀手。它轻轻歪一下身体，半眯眼看向手机镜头，露出“算了随便发”的小笑。手机在结尾出现一次自然拍照闪光，手臂和头顶符号不能拉长或变形。镜头有非常轻微的随手自拍晃动。
```

建议音效：轻松“咔嚓”声。

## 04｜通知爆发，4 秒

使用：`../03-visuals/keyframes-v1/04-viral-800000.png`

```text
从手机附近连续弹出红色爱心通知图标，先少后多，沿自然弧线向上飘散，不遮挡小内耗的脸。手机暖光逐渐照亮面部。小内耗先眨一次眼，然后原本的卡通眼睛适度睁大、身体轻微后仰、嘴巴变成一个小圆口，表现难以置信。表情要搞笑但不能恐怖，眼睛绝不能突出眼眶。镜头快速但平稳地轻推近。
```

建议音效：连续消息提示音 + 一次震惊音效。

## 05｜瘫倒怀疑人生，5 秒

使用：`../03-visuals/keyframes-v1/05-slump-question-marks.png`

```text
夜间剪辑室恢复安静。手机上剩余的爱心通知逐渐减少并淡出。小内耗瘫在椅子里，双臂自然垂放，缓慢眨一次眼，再轻轻叹气；身体只做很小的呼吸起伏。三个灰色问号缓慢漂浮，不能增加更多符号。镜头非常缓慢地拉远，最后停留约0.7秒，形成干涩搞笑的收尾。
```

建议音效：通知骤停 + 一声轻叹 + 搞怪收尾音。
