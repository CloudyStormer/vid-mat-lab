# 第 014 集制作剧本 v1｜21 秒生产版

## 制作原则

- 黑屏大字只在剪辑软件制作；视频模型不生成汉字。
- 10 个视频 clip 全部独立生成，每段只有一名说话者和一个主要可见动作。
- 小耗儿的六个请求用后期标签交代，不再与 NPC 同镜轮流说话。
- 六个职业 NPC 统一使用 `VO-NPC-01`，让“没人惯你”形成像系统提示一样的重复梗。
- 每条源片必须带同步人声和极轻连续环境底噪；所有一次性拟音、BGM 和人群声后期添加。

## 生产加强说明

1. 原稿全部对白完整保留在研究目录，生产版不伪装成原稿原文。
2. 六场景不再生成小耗儿请求口播，避免 2 秒内双人抢词；请求以字幕标签和道具状态表达。
3. 面馆只倒一次肉，便利店只递一次袋，奶茶只加一勺，外卖只落一个箱，办公室只拨一个开关，理发店只滑一张卡。
4. NPC 不走路、不转身、不做第二个表情；小耗儿闭嘴静止，不抢 NPC 台词。
5. 黑金卡、包装、纸箱、电脑、菜单和钱币全部无字无标志，避免 AI 乱码和现实品牌侵权。
