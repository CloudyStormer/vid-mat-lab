# 第 014 集声音锚点登记 v1｜批量生成硬门槛

`VO-XH-01` 与 `VO-NPC-01` 当前只是项目内部逻辑声音编号，不等于平台已经锁定的真实 Voice ID。仅重复文字描述不能保证跨 clip 声纹一致。

只有完成 6—10 秒干声样片、人工确认音色，并把实际平台参数与参考音频登记完整后，对应声音配置才允许进入批量生成。未登记前，[图生有声视频提示词](../04-prompts/video-prompts-v1.md) 中的方括号占位符不得保留，更不得直接把 `VO-XH-01` / `VO-NPC-01` 填进平台 Voice ID 字段。

## 建议干声锚点文本

### `VO-XH-01`

```text
我妈说过，外面没人惯着你。长大才发现，这诅咒真让人头疼。点赞留言，也会中同款哦。
```

要求：普通话青年男声，中低音、近讲干声、略疲惫但清醒、冷静利落；按每秒约 5.0—5.6 个汉字自然朗读。最后一句只增加一点调皮力度，不改变基础音高、年龄感或录音距离。

### `VO-NPC-01`

```text
没人惯你，肉加满！零钱拿好！布丁加满！全送上门！准点下班！黑卡免费！
```

要求：普通话成年中性偏低声，近讲干声、短促、嘴硬、利落、不怒吼、不油腻；按每秒约 5.2—5.8 个汉字自然朗读。六句必须保持同一音色和同一录音状态。

## 干声样片要求

- 每套声音 6—10 秒，普通话完整句；无 BGM、无环境声、无混响、无变声、无合声和无情绪滤镜。
- 同一逻辑编号后续所有 clip 必须复用登记表中的同一实际 Voice ID 或同一参考音频、同一模型版本与同一 seed / 复现参数。
- 情绪只允许调整力度和停顿，不得改变基础音高、共振峰、年龄感、性别感、口音、话筒距离或录音质感。
- 参考音频必须放在本集或项目内稳定路径，并记录 SHA-256；禁止只引用下载缓存、浏览器临时文件或会失效的外部 URL。
- 平台若没有 Voice ID 或参考音频功能，必须明确记录能力限制；优先使用同一已验收 TTS 生成全部干声后再同步混入。无法复用同一声音资产时，停止批量生成，不能标记“声纹已锁定”。
