# 第 014 集用户确认原稿 v2｜有来有回版

## 用户明确要求

- 不采用 v1 中“NPC 单方面发福利”的感觉。
- 每个生活场景必须先由小耗儿提出要求，再由 NPC 嘴硬回怼，形成完整的有来有回。
- 剧情核心保持：小时候被说“在外面没人惯着你”，长大后触发反向 Buff——要啥不给啥，不要啥偏给你啥。
- 画幅为抖音竖屏 9:16，延续小耗儿系列 Q 版手绘画风。
- 下列对白和场景是本版唯一剧情底稿；生产阶段不得把双向对话改回单向旁白。

## 用户原稿

### 0—3 秒｜钩子与设定

先黑屏炸出大字“在外面可没人惯着你！！”，切到小耗儿站在街头，快速闪回小时候妈妈训话。

小耗儿独白：

```text
我就像被我老娘诅咒了一样，长大后真的没人惯着我，要啥不给啥，不要啥偏给我啥。
```

### 牛肉面

```text
小耗儿：老板，牛肉面不要肉。
老板：没人惯着你挑三拣四！全给我吃！
```

### 找零

```text
小耗儿：不用找零了。
老板：没人惯着你占小便宜！拿着！
```

### 奶茶

```text
小耗儿：奶茶不要加布丁。
店员：没人惯着你喝寡茶！全加上！
```

### 外卖快递

```text
小耗儿：外卖不用送上来，放驿站就行。
外卖员：没人惯着你跑驿站！全给你送上来！
```

### 下班

```text
小耗儿：我再改完这版就走……
老板：没人惯着你蹭加班！全给我下班！
```

### 理发店

```text
小耗儿：我想充个会员。
理发师：没人惯着你乱花钱！黑金卡拿好，以后剪头全免费！
```

### 终极懵圈

```text
我怎么觉得……不太对呢？
```

### 结尾屏幕文字

```text
合着我这诅咒，是来享福的？
```

```text
你最想“不要”啥？评论区说，说不定就实现了。
```

## 身份解释

用户原稿中的“小耗”“小耗子”均按项目规范解释为固定 IP“小耗儿”的口语简称，不代表老鼠物种。画面仍必须使用永久原版白色圆形电阻人，不得生成鼠耳、鼠尾、毛发、长鼻或门牙。
