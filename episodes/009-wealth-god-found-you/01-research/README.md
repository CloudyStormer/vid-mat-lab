# “送财神”短视频结构研究

## 公开样本

- 抖音公开作品：[接财神啦！2026 马年，第一波大财气已送达](https://www.douyin.com/video/7608867403010690323)
- 抖音公开作品：[正月初六送穷神，穷神走，财神到](https://www.douyin.com/video/7609505450250102971)
- 公开视频样本镜像：[你今年要交大运，财神送福到门前](https://tikwm.com/video/7521327773378432274.html)

## 可复用的结构

1. 前 1 秒直接喊停或点名观众。
2. 立即说“找到你了”或“财气送到了”，制造被选中的轻喜感。
3. 用“接住”配合金币、元宝冲向镜头，形成明确动作点。
4. 用一句短祝福收尾，方便观众记住。

## 本集的改写原则

- 只借用公共题材和通用节奏，不照搬其他账号的成片、配音和独特表达。
- 不使用“点赞、转发、评论后才会发财”等强迫互动话术。
- 不承诺真实收益；“只许进账”是角色化的轻松祝福。
- 结尾必须回到账号主线：“不许内耗，只许进账”。
