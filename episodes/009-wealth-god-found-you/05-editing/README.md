# 剪辑方案

## 时间轴

| 时间 | 画面 | 声音 |
|---|---|---|
| 0.0—0.8 秒 | 轻微前倾、锁定镜头 | “哎，别划！” |
| 0.8—2.8 秒 | 得意地认出观众 | “财神可算找到你了。” |
| 2.8—4.3 秒 | 右手撒金，金币冲向镜头 | “金子来喽，接住！”＋金币叮当 |
| 4.3—7.2 秒 | 收手、蓝色电路轻亮 | “今天不许内耗，只许进账。” |
| 7.2—8.0 秒 | 微笑收势，画面停稳 | “发财啦！”＋轻锣点 |

## 字幕

- 使用大号白字、黑色细描边，放在画面下方安全区。
- 每次只放一个短句，不做满屏大字，不遮挡灰色电阻腰带。
- “接住”“不许内耗”“只许进账”可以分别用金色、浅灰、金色强调。

## 音频

- 人声峰值建议约 `-6 dB`。
- BGM 比人声低约 `12—16 dB`。
- “接住”处只放一次清脆金币音，不连续堆叠音效。
- 结尾留 0.3 秒稳定画面，避免平台循环播放时突然断掉。

## 导出

- 分辨率：1080×1920
- 帧率：与生成素材一致，优先 30 fps
- 编码：H.264
- 码率：建议 12—20 Mbps
