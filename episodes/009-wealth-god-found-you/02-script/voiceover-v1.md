# 口播 v1

## 最终口播

```text
哎，别划！财神可算找到你了。金子来喽，接住！今天不许内耗，只许进账。发财啦！
```

## 8 秒节奏

| 时间 | 口播 | 情绪与停顿 |
|---|---|---|
| 0.0—0.8 秒 | 哎，别划！ | 突然喊住，短促、有笑意；“划”后停一下 |
| 0.8—2.8 秒 | 财神可算找到你了。 | 像终于追到观众，带一点得意 |
| 2.8—4.3 秒 | 金子来喽，接住！ | “来喽”上扬；“接住”与撒金币同步 |
| 4.3—7.2 秒 | 今天不许内耗，只许进账。 | 稍微放稳，像认真宣布一条新规 |
| 7.2—8.0 秒 | 发财啦！ | 明亮、干脆，尾音不拖长 |

## 配音要求

- 年轻、机灵、喜气，语速略快，但每个短句清楚。
- 不是庄严的财神腔，也不是算命口吻。
- 不要尖叫，不要播音腔，不要过度油腻。
- “别划”“接住”“发财啦”三个词要有明显重音。

## 字幕

字幕可以按五个短句分别出现：

```text
哎，别划！
财神可算找到你了
金子来喽，接住！
今天不许内耗
只许进账，发财啦！
```
